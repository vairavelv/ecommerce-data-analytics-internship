# eCommerce Data Analytics Strategy — Working Project

A simple, working implementation of the strategy described in
`eCommerce Data Analytics Strategy Report`. Built deliberately with a
small, easy-to-explain stack:

- **CSV files** as the data store (`data/orders.csv`, `data/funnel_events.csv`)
- **Pandas** for data cleaning and analysis
- **NumPy** for the forecasting calculation
- **Matplotlib** for charts
- **Streamlit** for the dashboard UI

No database, no cloud services, no machine learning frameworks — just
enough to demonstrate the full analytics workflow end to end.

## What it does

| Report Section | Where it lives |
|---|---|
| 6. Data Preparation & Quality | `src/data_utils.py -> clean_orders()` |
| 7. KPIs | `src/data_utils.py -> compute_kpis()` |
| 8. Customer Segmentation (RFM) | `src/data_utils.py -> rfm_segmentation()` |
| 9. Purchase Funnel Analysis | `src/data_utils.py -> funnel_summary()` |
| 10. Market & Trend Analysis | `src/data_utils.py -> sales_trend()`, `sales_by_day_of_week()` |
| 12. Predictive Analytics | `src/data_utils.py -> forecast_revenue()` (NumPy linear-trend model, backtested against a naive baseline) |
| 14. Dashboard Design | `app.py` — Overview / Sales Trends / Products / Customers / Funnel / Marketing / Regions / Predictive / Insights tabs |

## Setup

```bash
# 1. clone the repo
git clone https://github.com/<your-username>/ecommerce-analytics-strategy.git
cd ecommerce-analytics-strategy

# 2. create a virtual environment (optional but recommended)
python -m venv venv
source venv/bin/activate       # Windows: venv\Scripts\activate

# 3. install dependencies
pip install -r requirements.txt

# 4. (re)generate the sample data — optional, orders.csv/funnel_events.csv
#    are already included in the repo, but you can regenerate fresh data
python data/generate_data.py

# 5. run the dashboard
streamlit run app.py
```

Then open the URL Streamlit prints (usually `http://localhost:8501`).

## Using your own data

Replace `data/orders.csv` with a real export that has these columns
(rename to match if needed):

```
order_id, customer_id, order_date, product_id, product_name, category,
quantity, unit_price, discount, shipping_cost, payment_method,
region, traffic_source, device_type, order_status
```

and `data/funnel_events.csv` with:

```
session_id, customer_id, date, device_type, traffic_source, stage
```

where `stage` is one of `Visit, Product View, Add to Cart, Checkout, Purchase`.

Everything downstream (cleaning, KPIs, RFM, funnel, forecast) works
automatically as long as the column names match.

## Notes

- The included CSVs contain **synthetic data** generated by
  `data/generate_data.py` — safe to share publicly, no real customer
  information.
- The forecast in the "Predictive" tab is intentionally simple
  (`numpy.polyfit` linear trend) to match the report's recommendation
  of starting with a student-level model and a simple baseline before
  introducing scikit-learn or other ML tooling.
- Data privacy: the project only uses anonymized/synthetic customer
  IDs, matching Section 18 of the strategy report.
